# Welcome to My Mind — Portfolio de Pinel LOKONON

Portfolio one-page à défilement scénarisé (style « jidekel.com »), construit avec React + TypeScript + Vite.

## Lancer

```bash
npm install
npm run dev      # développement
npm run build    # build de production (dossier dist/)
```

## Structure

- `src/data.ts` : toutes les informations (profil, projets, compétences, expériences, formations)
- `src/App.tsx` : sections (boot, landing, welcome, native prompt, who I am, credits, pick a side) + pages `#/analytical` et `#/creative`
- `src/Brain.tsx` : cerveau en particules (canvas)
- `src/styles.css` : design system (couleurs, typographies, cadre, grille)
- `public/assets/` : photos, captures de projets et CV
